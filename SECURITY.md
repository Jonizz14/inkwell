# Security Policy

## Supported versions

Only the [latest release](../../releases/latest) gets fixes. Releases are built from `main` on
every push, so updating to the newest one is the fix.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through GitHub:
**Security → [Report a vulnerability](../../security/advisories/new)**.

Include what an attacker could do, the steps to reproduce it, and the Inkwell version and OS.
You'll get an answer within a week. Once it's fixed, you'll be credited in the advisory if you want.

## What Inkwell does with your data

Inkwell runs offline and has no account, server or tracking. Your PDFs and notes stay in the app's
data folder on your computer; OCR runs on the device. The only thing that goes online is the music
player, for the YouTube links you add to it. Reports about anything that sends data
elsewhere, reads files outside the app's folders, or runs content from a PDF as code are especially
welcome.
